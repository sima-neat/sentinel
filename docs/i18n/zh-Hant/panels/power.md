# 電源面板

Sentinel 在專用的執行緒中取樣 PMBus，並將 `POUT` 暫存器中的值記錄下來。預設間隔為 100 毫秒。由於一般的快取間隔較長，因此使用者介面會發布最新的累積狀態，而不是顯示每個原始的 PMBus 取樣值。

## 標題欄位

| 欄位 | 計算 |
| --- | --- |
| 目前 | 在最近一次成功的 PMBus 傳輸過程中，成功讀取的所有軌道的總和，且至少有一個軌道成功讀取。 |
| 會期平均值 | 自守護程式啟動以來，所有有效總樣本的算術平均值。只要至少有一個通道成功，即視為一次通過。 |
| 會話高峰 | 自守護程式啟動以來，有效總樣本數的上限。 |
| 時長 | 自電力累積器開始運作以來經過的單調時間。 |
| 有效的樣本 | PMBus 測試時，至少會讀取一條已設定的電壓軌。 |
| 檢測失敗的樣本 | PMBus 傳輸過程中，沒有讀取到任何已設定的電壓軌。 |

每次重新啟動守護程式時，所有會話統計資料都會重設。

## 收藏家聲稱

- **處於作用狀態**：至少存在一個有效的樣本，且最新的測試結果包含資料，並且
  目前沒有軌道錯誤。
- **品質降低**：存在有效的資料，但最新的測試完全失敗，或是在以下情況下失敗。
  至少有一個軌道回報了錯誤。
- **無法取得**：尚未收集到有效的總數。

在部分故障期間，「即時值」、「平均值」和「峰值」總數可能少於正常樣本中的數值。如果一個測試完全失敗，「即時值」和所有軌道功率值都會保留其最後一次成功的讀數；失敗的樣本和軌道錯誤會增加，狀態會變為「退化」。請勿將保留的值解讀為來自失敗測試的測量值，也不要將部分總數和完整總數視為測量相同邊界的值。

## 鐵路表格欄位

- **Power** 是該軌道目前最新的成功讀取結果。如果之後有
  讀取失敗時，此值會維持在上次成功讀取時的值，而「錯誤」計數則會增加。
- **樣本數**：統計自守護程式啟動以來，該軌道成功讀取的次數。
- **錯誤** 欄位會計算特定電壓軌上，頁面選擇失敗或 PMBus 暫存器讀取失敗的次數。

對於部分成功的測試，總計僅使用在該次測試中成功的軌道，而每個軌道列則保留其最後一次成功的數值。對於完全失敗的測試，總計和軌道列都會保留較早的數值。因此，在部分失敗的情況下，對可見的軌道列進行加總可能會與「目前」的數值不同，而且在完全失敗後，這兩種數值都不會是新的。

## Modalix SOM 鐵路

| 鐵軌 | 它提供什麼？ |
| --- | --- |
| `SoC and DDR VDD` | 主要系統單晶片 (SoC) 和 DDR 領域；SoC 邏輯、記憶體控制器和 DDR 活動均有所貢獻。 |
| `HDMI 1.2V` | HDMI 1.2 版的 PHY 以及相關電路。 |
| `SoC and DDR VDDQ` | 記憶體控制器與 DDR 裝置之間的 DDR I/O 訊號域。 |
| `SoC and DDR VDD2H` | 額外的系統單晶片 (SoC)/DDR 記憶體電源域。 |
| `MLA 0.68V` | 0.68V 的 MLA 核心供電以及與 MLA 運算最直接相關的電壓軌。 |
| `PCIe and ETH VP` | PCIe 和乙太網路 PHY/平台領域。 |
| `SOM Platform 1.8V` | 共享 1.8V SOM 平台和周邊電路。 |
| `SOM Platform 3.3V` | 共享 3.3V SOM 平台和周邊電路。 |

`SoC and DDR VDD` 和 `MLA 0.68V` 的報告步驟為 0.25 W。其他標準 SOM 電壓軌的步驟為 0.03125 W。因此，在樣本數量增加且錯誤為零的情況下，`0.00 W` 是一個有效的零值暫存器讀取值，表示在該電壓軌的解析度下，讀取值為零，而不是感測器讀取失敗。

Modalix DVT 設定檔僅顯示 `DVT PMIC 0x4d page0`。其總值不能直接與八個電壓軌的 SOM 總值進行比較。

## 測量邊界

目前監測的是板載電源軌，而非交流市電或整個系統的輸入電源。它可以排除未監測的電源軌、穩壓器損耗、載板元件、儲存裝置、風扇和主機端裝置。

同樣地，模型能量並非僅由 `MLA 0.68V` 來表示。推論還會使用 DDR、SoC 和平台電源軌。在比較不同執行結果時，請記錄設定檔、電源軌健康狀況、Sentinel 版本、工作負載時間範圍以及環境/板載條件。
