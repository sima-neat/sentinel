# 裝置類型

每種裝置類型都有一個頁面描述其記錄：如何識別裝置、詳細資料中的每個欄位，
以及在真實硬體上驗證的內容。應用程式開發者會閱讀這些頁面來使用目錄。

| 類型 | 提供者 | 頁面 |
| --- | --- | --- |
| `camera` | `daemon.camera.mipi`, `daemon.camera.v4l2` | [相機](camera.md) |

## 加入類型

1. 將 [TEMPLATE.md](TEMPLATE.md) 複製為 `<type>.md`，並填寫每個章節。
2. 在上表加入一列。
3. 依照[加入裝置類型](../adding-a-device-type.md)建立提供者本身。

類型可以隨時新增欄位；用戶端會忽略不認識的欄位。重新命名或移除欄位，
或改變其含義，都會破壞用戶端，因此應改用新的欄位名稱。
