# 裝置類型

每種設備類型都有一個頁面描述其記錄：設備如何被識別、其詳細資訊的每個欄位，以及在實際硬體上驗證了什麼。應用程序開發人員閱讀這些頁面以使用目錄。

| 類型 | 提供者 | 頁面 |
| --- | --- | --- |
| `camera` | `daemon.camera.mipi`, `daemon.camera.v4l2` | [相機](camera.md) |
| `microphone` | `daemon.audio.alsa` | [麥克風](microphone.md) |

## 新增一種類型

1. 將 [模板.md](TEMPLATE.md) 複製到 `<type>.md`，並填寫每個部分。
2. 在上表中新增一列。
3. 請按照 [新增裝置類型](../adding-a-device-type.md) 為提供者操作
   本身。

欄位可以隨時新增到一種類型；用戶端會忽略他們不認識的欄位。重新命名或移除欄位，或改變其含義，會破壞用戶端，這時需要使用新的欄位名稱。
