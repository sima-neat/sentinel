# <Type name>

<!-- One paragraph: what this type covers and which devices are in its class. -->

- **Токен типу:** `<type>`
- **Провайдери:** `<provider name>`
- **Тригери повторного сканування:** `<uevent subsystems>`

## Ідентичність

Як утворюється `id`, з яких стабільних атрибутів і що зберігає його стабільність після перепідключень,
перезавантажень і перенумерації. Приклад: `<type>:<stable key>`.

## Приклад запису

```json
{"id": "<type>:...", "type": "<type>", "provider": "...", "<type>": {}}
```

## Охоплені варіації

Перелічіть, як відрізняються пристрої цього класу і як обробляється кожен варіант
(кількість, формати, діапазони, необов’язкові поля, складені пристрої, кілька однакових пристроїв,
значення, що змінюються під час використання).

## Правила підтримки

Чи класифікують правила компонента Neat цей тип і які поля вони читають.
Напишіть «немає», якщо тип не має класифікації підтримки.
