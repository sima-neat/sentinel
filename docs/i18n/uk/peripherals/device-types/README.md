# Типи пристроїв

Кожен тип пристрою має сторінку з описом його запису: як ідентифікуються пристрої, усі поля подробиць
і що було перевірено на реальному обладнанні. Розробники застосунків читають ці сторінки для роботи з каталогом.

| Тип | Провайдери | Сторінка |
| --- | --- | --- |
| `camera` | `daemon.camera.mipi`, `daemon.camera.v4l2` | [Камери](camera.md) |

## Додавання типу

1. Скопіюйте [TEMPLATE.md](TEMPLATE.md) до `<type>.md` і заповніть кожен розділ.
2. Додайте рядок до таблиці вище.
3. Для самого провайдера дотримуйтеся [додавання типу пристрою](../adding-a-device-type.md).

Поля можна додавати до типу будь-коли; клієнти ігнорують невідомі поля. Перейменування або видалення поля
чи зміна його значення порушує роботу клієнтів, тому натомість потрібно додати нове ім’я поля.
