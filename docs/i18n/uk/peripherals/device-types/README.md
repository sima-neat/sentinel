# Типи пристроїв

Кожен тип пристрою має сторінку, що описує його запис: як пристрої ідентифікуються, кожне поле його деталей і що було перевірено на реальному обладнанні. Розробники додатків читають ці сторінки, щоб користуватися каталогом.

| Тип | Постачальники | Сторінка |
| --- | --- | --- |
| `camera` | `daemon.camera.mipi`, `daemon.camera.v4l2` | [Камери](camera.md) |
| `microphone` | `daemon.audio.alsa` | [Мікрофони](microphone.md) |

## Додавання типу

1. Скопіюйте [ШАБЛОН.md](TEMPLATE.md) у `<type>.md` та заповніть кожен розділ.
2. Додайте рядок до таблиці вище.
3. Дотримуйтесь [додавання типу пристрою](../adding-a-device-type.md) для постачальника
   саме.

Поля можуть бути додані до типу в будь-який час; клієнти ігнорують поля, яких вони не знають. Перейменування або видалення поля, або зміна його значення порушує роботу клієнтів і потребує нового імені поля.
