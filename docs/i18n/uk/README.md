# Документація Sentinel

Sentinel збирає телеметрію Modalix DevKit у фоновому демоні, записує
атомарний кеш JSON і відображає цей кеш у звітах у терміналі. Ці сторінки
пояснюють, що показує кожна панель, звідки береться кожне значення, як воно
обчислюється та які його обмеження.

## Панелі подання операцій

| Панель | Документація | Призначення |
| --- | --- | --- |
| Огляд | [Панель огляду](panels/overview.md) | Основні показники стану: тепловий режим, живлення, CPU, пам’ять, пам’ять MLA, накопичувачі та мережа. |
| Тепловий режим | [Теплова панель](panels/thermal.md) | Точки RTSN/PVT на кристалі та показання апаратного моніторингу на рівні плати. |
| Живлення | [Панель живлення](panels/power.md) | Потужність ліній живлення PMBus, сумарні значення, середнє/пікове значення за сеанс і стан колектора. |
| Система | [Системна панель](panels/system.md) | Сукупне та поядерне завантаження CPU, середнє навантаження, пам’ять Linux, виділення пам’яті MLA, пам’ять EV74 CMA і процеси. |
| Накопичувачі/Мережа | [Панель накопичувачів і мережі](panels/storage-network.md) | Ємність і введення/виведення eMMC/NVMe, а також сукупний мережевий трафік. |

## Звіти та поведінка збору даних

- [Модель вимірювання](measurement-model.md) пояснює періодичність роботи колекторів, історію
  кешу, семантику діаграм, порогові значення, застарілі дані, недоступні значення та
  поведінку під час скидання.
- [Звіти та експорт JSON](reports.md) документує схему кешу та
  команди `table`, `export`, `sensors` і `status`.
- [Локальний API агента](api.md) документує читання даних у реальному часі та керування трасуванням через
  сокет Unix демона.
- [Захоплення та порівняння запусків](run-comparison.md) документує постійні
  контрольні точки, вкладку Compare Runs, строк зберігання та експорт у CSV/JSON.

[Локальний API агента](api.md#peripherals) описує каталог і спосіб його
оновлення; кожен тип пристрою має власну сторінку:

- [USB-камери](peripherals/camera.md) (V4L2)
- [Камери MIPI CSI-2](peripherals/camera-mipi.md)
- [Мікрофони](peripherals/microphone.md) (ALSA)
- [Конфігурація камер плати](peripherals/board.md): модель, оверлеї
  камер, а також налаштовані й підтримувані сенсори
- [Додавання типу пристрою](peripherals/adding-a-device-type.md) — для учасників розробки
