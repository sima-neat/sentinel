# Документація до Sentinel

Sentinel збирає телеметричні дані Modalix та DevKit у фоновому процесі, записує їх в
атомарний кеш JSON і відображає цей кеш у вигляді звітів у терміналі. На цих сторінках
пояснюється, які дані відображає кожна панель, звідки беруться ці значення, як вони
обчислюються та які їхні обмеження.

## Панелі для відображення інформації про поточні операції.

| Панель | Документація | Мета. |
| --- | --- | --- |
| Огляд | [Панель огляду](panels/overview.md) | Основні показники: тепловий стан, енергоспоживання, стан центрального процесора, стан пам’яті, стан пам’яті MLA, стан накопичувачів даних і стан мережі. |
| Тепловий | [Теплова панель](panels/thermal.md) | Вбудовані датчики RTSN/PVT та показання апаратного монітора на рівні друкованої плати. |
| Потужність. | [Панель керування живленням](panels/power.md) | Напруга живлення шини PMBus, загальні значення, середнє/максимальне значення за сесію та стан колектора. |
| Система | [Системна панель](panels/system.md) | Загальне/індивідуальне навантаження на кожне ядро процесора, середнє навантаження, пам’ять Linux, розподіл пам’яті MLA, пам’ять EV74 CMA та процеси. |
| Місце для зберігання/Об’єм мережі | [Панель зберігання даних і мережі](panels/storage-network.md) | Обсяг пам’яті eMMC/NVMe та швидкість вводу/виводу даних, а також загальний обсяг мережевого трафіку. |

## Звіти та поведінка під час стягнення боргів.

- [Модель вимірювання](measurement-model.md) пояснює частоту збору даних, кеш.
  історія, семантика діаграм, порогові значення, застарілі дані, недоступні значення та
  поведінка під час скидання.
- [Звіти та експорт у формат JSON: ](reports.md) містить документацію щодо схеми кешу та
  Команди: `table`, `export`, `sensors` та `status`.
- [Локальний API агента](api.md) забезпечує відстеження даних у реальному часі та контроль над процесом.
  демона Unix роз’єм.
- [Збір і порівняння результатів виконання](run-comparison.md) документів, що зберігаються.
  контрольні точки, вкладка «Порівняння результатів», збереження даних та експорт у формати CSV і JSON.
