# Sentinel 설명서

Sentinel은 백그라운드 데몬에서 Modalix DevKit 텔레메트리 데이터를 수집하고, 원자적 JSON 캐시를 작성한 다음, 해당 캐시를 터미널 보고서를 통해 표시합니다. 이 페이지에서는 각 패널이 보고하는 내용, 각 값의 출처, 계산 방법, 그리고 해당 값의 제한 사항에 대해 설명합니다.

## 운영 현황 패널

| 패널 | 문서 | 목적 |
| --- | --- | --- |
| 개요 | [개요 패널](panels/overview.md) | 주요 항목: 온도, 전력, CPU, 메모리, MLA 메모리, 저장 장치, 네트워크 상태. |
| 열 | [열 패널](panels/thermal.md) | 칩 내부에 있는 RTSN/PVT 센서와 보드 수준의 하드웨어 모니터링 값. |
| 전력 | [전원 패널](panels/power.md) | PMBus 전원 레일, 총합, 세션 평균/최댓값, 그리고 수집기 상태. |
| 시스템 | [시스템 패널](panels/system.md) | 전체/코어별 CPU, 평균 부하, Linux 메모리, MLA 할당, EV74 CMA 메모리 및 프로세스. |
| 저장 공간/네트워크 | [저장 장치 및 네트워크 패널](panels/storage-network.md) | eMMC/NVMe 용량 및 I/O 성능과 총 네트워크 트래픽. |

## 보고 및 수집 동작

- [측정 모델](measurement-model.md)은 데이터 수집 주기와 캐시를 설명합니다.
  기록, 차트 의미, 임계값, 오래된 데이터, 사용할 수 없는 값, 그리고 재설정 동작.
- [보고서 및 JSON 내보내기](reports.md)는 캐시 스키마와 해당 내용을 문서화합니다.
  `table`, `export`, `sensors` 및 `status` 명령어.
- [로컬 에이전트 API](api.md)는 실시간 데이터 읽기 및 추적 제어를 기록합니다.
  데몬의 Unix 소켓입니다.
- [실행 결과를 캡처하고 비교](run-comparison.md)는 지속적인 데이터를 기록합니다.
  체크포인트, 비교 실행 탭, 보존 기능, 그리고 CSV/JSON 형식으로 내보내기.
