# 장치 유형

각 장치 유형에는 장치 식별 방식, 세부 정보의 모든 필드, 실제 하드웨어에서 검증한 내용을 포함해 레코드를
설명하는 페이지가 있습니다. 애플리케이션 개발자는 카탈로그를 사용하기 위해 이 페이지를 읽습니다.

| 유형 | 공급자 | 페이지 |
| --- | --- | --- |
| `camera` | `daemon.camera.mipi`, `daemon.camera.v4l2` | [카메라](camera.md) |

## 유형 추가

1. [TEMPLATE.md](TEMPLATE.md)를 `<type>.md`로 복사하고 모든 섹션을 작성합니다.
2. 위 표에 행을 추가합니다.
3. 공급자 자체는 [장치 유형 추가](../adding-a-device-type.md)를 따릅니다.

유형에는 언제든 필드를 추가할 수 있으며 클라이언트는 모르는 필드를 무시합니다. 필드 이름을 바꾸거나 제거하거나
의미를 변경하면 클라이언트가 깨지므로 대신 새 필드 이름을 사용해야 합니다.
