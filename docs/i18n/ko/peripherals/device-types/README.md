# 장치 유형

각 장치 유형에는 해당 기록을 설명하는 페이지가 있습니다.
각 분야의 세부사항과 실제 검증된 내용을
하드웨어. 애플리케이션 개발자는 카탈로그를 사용하기 위해 이 페이지를 읽습니다.

| 유형 | 공급자 | 페이지 |
| --- | --- | --- |
| `camera` | `daemon.camera.mipi`, `daemon.camera.v4l2` | [카메라](camera.md) |
| `microphone` | `daemon.audio.alsa` | [마이크](microphone.md) |

## 유형 추가

1. [템플릿.md](TEMPLATE.md)를 `<type>.md`에 복사하고 모든 섹션을 채웁니다.
2. 위의 테이블에 행을 추가합니다.
3. 공급자에 대해서는 [장치 유형 추가](../adding-a-device-type.md)을 따르세요.
   그 자체.

필드는 언제든지 유형에 추가될 수 있습니다. 클라이언트는 자신이 사용하지 않는 필드를 무시합니다.
알아요. 필드 이름을 바꾸거나 필드를 제거하거나 의미를 변경하면 클라이언트가 중단됩니다.
대신 새 필드 이름이 필요합니다.
