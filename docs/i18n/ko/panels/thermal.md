# 열 패널

열 패널은 17개의 온도 채널을 표시합니다.

- Modalix SoC 내부에 있는 14개의 온다이 RTSN/PVT 채널
- LM96163과 호환되는 장치에서 보고된 두 개의 SOM 보드 온도 채널
  하드웨어 모니터링 장치
- 이더넷/MDIO 하드웨어 모니터링 채널 1개.

모든 값은 섭씨 단위입니다. 이는 센서 위치에서 측정한 지점 값이며, 주변 공기 온도나 평균 다이 온도가 아닙니다.

## 최대 열 용량

상위 차트는 각 캐시 샘플에 대해 모든 열 측정 지표에서 가장 높은 유한 온도를 선택합니다. 가장 뜨거운 센서는 샘플 간에 변경될 수 있습니다. 개별 센서 차트를 사용하여 원본을 식별하십시오.

## 칩 내부에 집적된 RTSN/PVT 센서

Sentinel은 Linux의 `simaai_modalix_thermal_sensor` hwmon 장치를 읽습니다. `temp1_input`부터 `temp14_input`까지는 `rtsn_0`부터 `rtsn_13`까지에 대응하며, 밀리섭씨 값을 1000으로 나누어 표시합니다. 측정 모드, 제어 순서 및 보정은 커널이 관리합니다.

Sentinel은 `/dev/mem`을 매핑하거나 PVT 컨트롤러에 쓰지 않습니다. 직접 접근은 커널과 충돌할 수 있으므로 대체 경로로도 사용하지 않습니다. hwmon 드라이버가 없으면 칩 내부 온도를 사용할 수 없습니다. 커널의 온도 보호 기능을 활성화 상태로 유지하십시오.

SoC에는 물리적 위치가 7곳 있습니다. 각 위치는 동일한 곳에 있는 경보 채널 RTSN과 트립 채널 RTSN으로 표시됩니다.

| 위치 | 알림 채널 | 여행 채널 |
| --- | --- | --- |
| MLA 사분면 Q0 | `MLA-0` | `MLA-7` |
| MLA 사분면 1 | `MLA-1` | `MLA-8` |
| MLA 사분면 2 | `MLA-2` | `MLA-9` |
| MLA 사분면 3분기 | `MLA-3` | `MLA-10` |
| APU | `APU-4` | `APU-11` |
| CVU | `CVU-5` | `CVU-12` |
| 상단, PCIe/이더넷 근처 | `TOP-6` | `TOP-13` |

이 두 값은 표시된 값에서 서로 다른 두 개의 온도 한계를 나타내는 것이 아닙니다. 대신, 동일한 위치에서 서로 다른 하드웨어 임계값 경로로 신호를 보내는 두 개의 센서 채널을 나타냅니다. 이 두 값 사이에는 약간의 차이가 있을 수 있습니다.

센서가 없거나 읽기에 실패하면 사용할 수 없음(JSON `null`)으로 표시합니다. 0이나 이전 값을 사용하지 않습니다. 다음 수집 시 다시 시도하며, 드라이버 재연결을 처리하기 위해 매번 hwmon 장치를 다시 검색합니다.

## 보드 및 이더넷 센서

| 표시 이름 | 출처 | 물리적 해석 |
| --- | --- | --- |
| `LM96-1` | `lm96163` `temp1_input` | 모니터링 IC의 내부 센서에서 측정한 SOM 상단 보드의 온도입니다. |
| `LM96-2` | `lm96163` `temp2_input` | SOM 하단에 있는 다이오드의 온도를 모니터링 IC를 통해 읽어 SOM 하단면의 온도를 측정합니다. |
| `ETH-1` | 이더넷/MDIO `temp1_input` | 이더넷 하드웨어 모니터링 장치에서 보고하는 온도입니다. 정확한 물리적 구성 요소는 아직 확인되지 않았습니다. |

Linux hwmon은 밀리도 단위의 섭씨 온도를 보고하며, Sentinel은 해당 값을 1000으로 나눕니다.

LM96163 디렉터리는 드라이버 이름으로 확인되는데, 이는 `hwmonN` 번호가 변경될 수 있기 때문입니다. 표시된 예시 경로는 안정적인 식별자가 아닙니다.

## 색상 및 임계값

- 청록색: 45°C 이하
- 녹색: 45°C에서 70°C 이하
- 빨간색/경고: 70°C에서 85°C 이하
- 굵은 글씨의 빨간색/중요: 85°C 이상

이 값들은 Sentinel의 발표 기준값입니다. 이 값들은 장치 데이터시트의 제한, 열 차단 동작 또는 보드별 작동 요구 사항을 대체하지 않습니다.
