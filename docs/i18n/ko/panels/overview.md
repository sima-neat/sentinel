# 개요 패널

개요 패널은 상세 패널에 표시된 동일한 지표를 바탕으로 구성된 요약 정보입니다. 별도의 데이터를 수집하지 않습니다.

## 주요 차트

| 차트 | 측정 지표/계산 방식 | 의미 |
| --- | --- | --- |
| 최대 열 용량 | 현재 사용 중인 모든 열 관련 지표에서 측정되는 최대 유한 온도 | 각 캐시 샘플에서 가장 높은 온도를 기록한 온다이 또는 보드 센서에 대한 정보를 제공합니다. 최대 온도를 기록하는 센서는 시간이 지남에 따라 변경될 수 있습니다. |
| 현재 전력 | `power_current_watts` | 해당 전원 경로에서 성공적으로 읽은 최신 유효한 총 PMBus 레일 값입니다. 부분적으로 읽는 방식에 대한 자세한 내용은 [Power](power.md)를 참조하십시오. |
| CPU | `cpu_usage_pct` | 집계 Linux 최신 시스템 샘플링 기간 동안 CPU 사용률. |
| 메모리 | `linux_mem_used_pct` | `(MemTotal - MemAvailable) / MemTotal × 100`. |
| MLA 메모리 | `mla_mem_allocated_mb` | `/dev/simaai-mem`에서 보고하는 할당된 바이트 수를 MiB 단위로 변환한 값입니다. 이는 MLA 사용량이 아닌 할당량 사용량을 나타냅니다. |
| 네트워크 | `net_rx_mbps + net_tx_mbps` | 모든 루프백 인터페이스를 제외한 인터페이스의 총 수신 및 전송 속도를 합산한 값입니다. 키 이름과는 달리, 표시되는 단위는 MiB/s와 동일하며, 메가비트/s는 아닙니다. |

열 최대값 차트는 가장 뜨거운 지점을 파악하는 데 유용하지만, 열 패널을 대체해서는 안 됩니다. 열 최대값 차트는 어떤 센서가 해당 지점에 해당하는지 숨기고, 다이 내부 센서와 보드 센서 간을 전환할 수 있습니다.

## 현재 상태 표

다음 표는 다음과 같은 내용을 보여줍니다.

- 정규화된 1분 단위 CPU 사용량
- Linux에서 사용 중인 메모리(MiB 단위);
- MLA 할당 메모리(MiB 단위);
- 현재 보드 레일 전원;
- eMMC 및 선택 사항인 NVMe 파일 시스템 사용;
- 전체 수신 및 전송 속도.

각 열의 의미는 다음과 같습니다.

- **지표**: 캐시 지표 정의에서 가져온 짧은 표시 이름입니다.
- **그룹**: 하위 시스템 범주.
- **값**: 가장 최근에 캐시된 값.
- **상태**: `normal`, `warning`, `critical` 또는 `unknown`이며, 이는 다음을 기준으로 합니다.
  지표의 구성된 임계값입니다.
- **동향**: 캐시 기록에 저장된 데이터에 대해 정규화된 스파클라인을 적용합니다.

## 메모 패널

‘메모’ 패널은 최상위 데몬 오류가 있을 때 해당 오류를 표시합니다. 데몬 오류가 없을 때는 사용법 안내를 표시합니다. ‘메모’ 패널이 비어 있다는 사실은 모든 센서가 정상적으로 작동한다는 증거는 아닙니다. 전원 상태는 자체적으로 저하될 수 있으며, 개별 측정값은 최상위 데몬 오류로 이어지지 않고도 사용할 수 없게 될 수 있습니다.
