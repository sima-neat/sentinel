# 전원 패널

Sentinel은 전용 스레드에서 250ms마다 커널의 PMBus 드라이버로부터 각 레일의 출력 전력(`POUT`)을 읽습니다. 일반 캐시 간격은 더 느리기 때문에 UI는 모든 전력 판독값을 표시하는 대신 최신 누적 상태를 게시합니다.

## 소스

각 레일은 PMBus 레귤레이터 hwmon 장치의 `pout` 채널 하나입니다: `/sys/bus/i2c/devices/<bus>-<address>/hwmon/hwmon*/power<N>_input`, 단위는 마이크로와트이며 `power<N>_label`이 채널 이름을 나타냅니다(예: PMBus 페이지 0의 경우 `pout1`). Sentinel은 장치를 I2C 주소로, 채널을 레이블로 찾으며 `hwmonN`이나 채널 번호로는 절대 찾지 않습니다. 커널 드라이버가 자체 잠금 아래에서 PMBus 페이지를 선택하고 레지스터를 읽으므로, 레귤레이터를 읽는 다른 프로그램이 Sentinel의 판독값을 손상시킬 수 없습니다.

Modalix에서 레귤레이터는 IRPS5401 장치입니다. 장치 트리에 선언되어 있지만 `irps5401` 모듈이 자동으로 로드되지 않으므로, Sentinel 서비스는 시작하기 전에 `modprobe irps5401`을 실행합니다. 바인딩된 드라이버가 없으면 전력을 사용할 수 없으며, 수집기 오류에 로드해야 할 모듈 이름이 표시됩니다.

## 제목 필드

| 필드 | 계산 |
| --- | --- |
| 현재 | 최신 패스에서 구성된 모든 레일의 합계입니다. 레일 중 하나라도 읽지 못하면 비어 있습니다. |
| 세션 평균 | 데몬 시작 이후 모든 완전한 패스 합계의 산술 평균입니다. 모든 레일을 읽은 패스를 완전한 패스로 간주합니다. |
| 세션 최고점 | 데몬 시작 이후 완전한 패스 합계의 최대값입니다. |
| 기간 | 전력 누적기가 시작된 이후 경과된 단조 시간입니다. |
| 유효한 샘플 | 구성된 모든 레일을 읽은 패스입니다. |
| 실패한 샘플 | 구성된 레일 중 하나 이상을 읽지 못한 패스입니다. |

데몬이 재시작되면 모든 세션 통계가 초기화됩니다.

## 수집가의 주장

- **활성 상태**: 완전한 패스가 최소 하나 존재하고, 최신 패스에서
  모든 레일을 읽었습니다.
- **저하됨**: 완전한 패스가 존재하지만, 최신 패스에서 최소 하나의
  레일을 읽지 못했습니다.
- **사용 불가능**: 완전한 패스가 수집되지 않았습니다.

Sentinel은 이전 판독값을 현재 값으로 표시하지 않습니다. 레일을 읽을 수 없으면 해당 레일의 전력 값과 현재 값은 다음 성공적인 패스까지 비어 있고, 실패한 샘플과 해당 레일의 오류가 증가하며, 상태는 저하됨(DEGRADED)으로 변경됩니다. 평균값과 최대값에는 완전한 패스만 포함되므로 모든 합계가 동일한 레일을 대상으로 합니다.

## 레일 테이블 필드

- **파워**는 최신 패스에서 읽은 해당 레일의 값이며, 해당 읽기가 실패하면
  비어 있습니다.
- **샘플**은 데몬 시작 이후 해당 레일에 대해 성공적으로 읽은 횟수를 나타냅니다.
- **오류**는 해당 레일의 커널 `power<N>_input` 파일 읽기에 실패한 횟수를 나타냅니다(예: 드라이버가 바인딩되지 않은 동안).

## Modalix SOM 레일

| 레일 | 어떤 것을 제공하는가 |
| --- | --- |
| `SoC and DDR VDD` | 주요 SoC 및 DDR 영역: SoC 로직, 메모리 컨트롤러, 그리고 DDR 작동이 기여합니다. |
| `HDMI 1.2V` | HDMI 1.2 버전 PHY 및 관련 회로. |
| `SoC and DDR VDDQ` | 메모리 컨트롤러와 DDR 장치 간의 DDR I/O 신호 영역입니다. |
| `SoC and DDR VDD2H` | 추가 SoC/DDR 메모리 전원 영역. |
| `MLA 0.68V` | 0.68V MLA 코어 전원 공급 장치와 MLA 연산과 가장 직접적으로 연결된 전원 레일. |
| `PCIe and ETH VP` | PCIe 및 이더넷 PHY/플랫폼 영역. |
| `SOM Platform 1.8V` | 1.8V SOM 플랫폼과 주변 회로를 공유합니다. |
| `SOM Platform 3.3V` | 공유된 3.3V SOM 플랫폼 및 주변 회로. |

`SoC and DDR VDD` 및 `MLA 0.68V`는 0.25W의 보고 단계를 갖습니다. 다른 표준 SOM 레일은 0.03125W의 단계를 갖습니다. 따라서 샘플 수가 증가하고 오류가 없는 `0.00 W`는 레일의 해상도에서 유효한 0 값을 갖는 레지스터 값을 나타내며, 센서 판독 오류가 아닙니다.

Modalix DVT 프로파일은 `DVT PMIC 0x4d page0`만 노출합니다. 따라서 총값은 8개의 레일로 구성된 SOM의 총값과 직접 비교할 수 없습니다.

## 측정 범위

현재는 보드 레일 전원을 모니터링하며, AC 전원 또는 전체 시스템 입력 전원은 모니터링하지 않습니다. 모니터링되지 않은 레일, 레귤레이터 손실, 캐리어 보드 구성 요소, 저장 장치, 팬, 호스트 측 장치를 제외할 수 있습니다.

마찬가지로 모델 에너지는 `MLA 0.68V`만으로는 표현되지 않습니다. 추론 과정에서도 DDR, SoC 및 플랫폼 레일을 사용합니다. 실행 결과를 비교할 때 프로필, 레일 상태, Sentinel 버전, 워크로드 기간, 주변/보드 조건을 기록합니다.
