# 전원 패널

Sentinel은 전용 스레드에서 PMBus 전력 레지스터를 샘플링합니다. Modalix SOM에서는 `SoM_Power_Share.py` 참조 방식을 따릅니다. 각 레일은 50회 읽은 값의 평균이므로 8개 레일을 한 번 측정하는 데 약 1초가 걸립니다. 일반 캐시 간격은 더 느리기 때문에 UI는 모든 원시 PMBus 샘플을 표시하는 대신 최신 누적 상태를 게시합니다.

## 제목 필드

| 필드 | 계산 |
| --- | --- |
| 현재 | 최근 PMBus 통신 과정에서 성공적으로 읽힌 레일의 합계입니다. 이 과정에서 최소 하나의 레일은 성공적으로 읽혔습니다. |
| 세션 평균 | 데몬 시작 이후 모든 유효한 전체 샘플의 산술 평균입니다. 적어도 하나의 레일이 성공하면 해당 테스트를 유효한 것으로 간주합니다. |
| 세션 최고점 | 데몬 시작 이후 유효한 총 샘플의 최대값입니다. |
| 기간 | 전력 누적기가 시작된 이후 경과된 단조 시간입니다. |
| 유효한 샘플 | PMBus는 구성된 전압 레일 중 최소 하나 이상의 값이 읽힌 경우에 발생합니다. |
| 실패한 샘플 | PMBus에서 구성된 전압 레일을 읽지 않은 경우에 발생합니다. |

데몬이 재시작되면 모든 세션 통계가 초기화됩니다.

## 수집가의 주장

- **활성 상태**: 유효한 샘플이 최소 하나 존재하고, 가장 최근의 통과 검사에서 데이터가 수집되었으며,
  현재 레일 관련 오류는 없습니다.
- **저하됨**: 유효한 데이터가 존재하지만, 최신 검사에서 완전히 실패하거나 일부 실패했습니다.
  최소 하나의 레일에서 오류가 발생했습니다.
- **사용 불가능**: 유효한 총합이 수집되지 않았습니다.

부분적인 오류가 발생하면 현재 값, 평균값, 최대값 합계에 정상 샘플보다 적은 레일 값이 포함될 수 있습니다. 테스트가 완전히 실패하면 현재 값과 모든 레일 전력 값은 마지막 성공적인 값을 유지합니다. 실패한 샘플과 레일 오류가 증가하고 상태는 저하됨(DEGRADED)으로 변경됩니다. 유지된 값을 실패한 테스트에서 측정한 값으로 해석하거나 부분적인 값과 완전한 값을 동일한 경계를 측정한 값으로 비교하지 마십시오.

## 레일 테이블 필드

- **파워**는 해당 레일에 적용된 가장 최근의 성공적인 설정값입니다. 이후에
  읽기 작업이 실패하면 이 값은 마지막 성공 시의 값을 유지하고, 오류 횟수는 증가합니다.
- **샘플**은 데몬 시작 이후 해당 레일에 대해 성공적으로 읽은 횟수를 나타냅니다.
- **오류**는 페이지 선택 또는 모든 PMBus 읽기가 실패하여 해당 레일이 값을 반환하지 못한 측정 횟수를 나타냅니다.

부분적으로 성공한 경우, 총합은 해당 단계에서 성공한 레일만 사용하고 각 레일 행은 마지막 성공 값을 유지합니다. 완전히 실패한 경우, 총합과 레일 행 모두 이전 값을 유지합니다. 결과적으로, 부분적인 실패가 발생하면 보이는 레일 행을 합산한 값은 현재 값과 다를 수 있으며, 완전히 실패한 후에는 두 값 모두 최신 값이 아닙니다.

## Modalix SOM 레일

| 레일 | 어떤 것을 제공하는가 |
| --- | --- |
| `SoC and DDR VDD` | 주요 SoC 및 DDR 영역: SoC 로직, 메모리 컨트롤러, 그리고 DDR 작동이 기여합니다. |
| `HDMI 1.2V` | HDMI 1.2 버전 PHY 및 관련 회로. |
| `SoC and DDR VDDQ` | 메모리 컨트롤러와 DDR 장치 간의 DDR I/O 신호 영역입니다. |
| `SoC and DDR VDD2H` | 추가 SoC/DDR 메모리 전원 영역. |
| `MLA 0.68V` | 0.68V MLA 코어 전원 공급 장치와 MLA 연산과 가장 직접적으로 연결된 전원 레일. |
| `PCIe and ETH VP` | PCIe 및 이더넷 PHY/플랫폼 영역. |
| `SOM Platform 1.8V` | 1.8V SOM 플랫폼과 주변 회로를 공유합니다. |
| `SOM Platform 3.3V` | 공유된 3.3V SOM 플랫폼 및 주변 회로. |

`SoC and DDR VDD` 및 `MLA 0.68V`는 출력 전압에 출력 전류를 곱해 계산하며, 전류 단계는 0.125A입니다. 다른 표준 SOM 레일은 PMBus 출력 전력 읽기 값을 사용하며, 단계는 0.03125W입니다. 따라서 샘플 수가 증가하고 오류가 없는 `0.00 W`는 레일의 해상도에서 유효한 0 값을 갖는 레지스터 값을 나타내며, 센서 판독 오류가 아닙니다.

Modalix DVT 프로파일은 `DVT PMIC 0x4d page0`만 노출하며, 250ms마다 `POUT` 값 하나를 읽습니다. 따라서 총값은 8개의 레일로 구성된 SOM의 총값과 직접 비교할 수 없습니다.

## 측정 범위

현재는 보드 레일 전원을 모니터링하며, AC 전원 또는 전체 시스템 입력 전원은 모니터링하지 않습니다. 모니터링되지 않은 레일, 레귤레이터 손실, 캐리어 보드 구성 요소, 저장 장치, 팬, 호스트 측 장치를 제외할 수 있습니다.

모든 합계는 추정값입니다. PMBus 장치가 보고하는 레귤레이터 읽기 값에서 도출한 레일별 출력 전력의 합이며, SOM 입력 전력을 보정하여 측정한 값이 아닙니다. Modalix SOM에서는 레지스터, 스케일링, 평균 방식이 참조 스크립트 `SoM_Power_Share.py`에 의해 정의됩니다. Sentinel은 해당 스크립트를 재현하며, 전력 상태의 `method` 필드에 스크립트 버전을 보고합니다.

마찬가지로 모델 에너지는 `MLA 0.68V`만으로는 표현되지 않습니다. 추론 과정에서도 DDR, SoC 및 플랫폼 레일을 사용합니다. 실행 결과를 비교할 때 프로필, 레일 상태, Sentinel 버전, 워크로드 기간, 주변/보드 조건을 기록합니다.
