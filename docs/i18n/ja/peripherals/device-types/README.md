# デバイスタイプ

各デバイスタイプには、そのレコード、デバイスの識別方法、詳細の全フィールド、実機で検証した内容を
説明するページがあります。アプリケーション開発者はカタログを利用するためにこれらのページを参照します。

| タイプ | プロバイダー | ページ |
| --- | --- | --- |
| `camera` | `daemon.camera.mipi`, `daemon.camera.v4l2` | [カメラ](camera.md) |

## タイプの追加

1. [TEMPLATE.md](TEMPLATE.md) を `<type>.md` にコピーし、すべてのセクションを記入します。
2. 上の表に行を追加します。
3. プロバイダー自体については[デバイスタイプの追加](../adding-a-device-type.md)に従います。

タイプにはいつでもフィールドを追加できます。クライアントは未知のフィールドを無視します。
フィールドの名前変更、削除、意味の変更はクライアントを壊すため、代わりに新しいフィールド名が必要です。
