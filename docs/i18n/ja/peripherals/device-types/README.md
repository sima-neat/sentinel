# デバイスの種類

各デバイスタイプには、その記録を説明するページがあります：デバイスがどのように識別されるか、その詳細のすべての項目、および実際のハードウェアで何が検証されたかです。アプリケーション開発者は、カタログを利用するためにこれらのページを読みます。

| タイプ | プロバイダー | ページ |
| --- | --- | --- |
| `camera` | `daemon.camera.mipi`, `daemon.camera.v4l2` | [カメラ](camera.md) |
| `microphone` | `daemon.audio.alsa` | [マイクロフォン](microphone.md) |

## 型を追加する

1. [TEMPLATE.md](TEMPLATE.md) を `<type>.md` にコピーし、すべてのセクションに記入してください。
2. 上の表に行を追加してください。
3. プロバイダーのために [デバイスタイプを追加する](../adding-a-device-type.md) に従ってください
   それ自体。

型にはいつでもフィールドを追加できます。クライアントは知らないフィールドを無視します。フィールドの名前を変更したり削除したり、意味を変更したりすると、クライアントが壊れるため、その場合は新しいフィールド名が必要です。
