# Sentinel のドキュメント

Sentinel は、バックグラウンドデーモンで Modalix DevKit のテレメトリーデータを収集し、アトミックな JSON キャッシュを作成し、そのキャッシュをターミナルレポートを通じて表示します。これらのページでは、各パネルがどのような情報をレポートするか、各値がどこから取得されるか、どのように計算されるか、そしてその限界が何であるかを説明します。

## 運用状況表示パネル

| パネル | ドキュメント | 目的 |
| --- | --- | --- |
| 概要 | [概要パネル](panels/overview.md) | 主要な熱、電力、CPU、メモリ、MLAメモリ、ストレージ、およびネットワークの状態を表示します。 |
| 熱 | [サーマルパネル](panels/thermal.md) | チップ上に実装されたRTSN/PVT測定ポイントと、ボードレベルのハードウェア監視機能による測定値。 |
| パワー | [電源パネル](panels/power.md) | PMBus：レール電圧、合計値、セッションの平均値/最大値、およびコレクターの状態。 |
| システム | [システムパネル](panels/system.md) | 合計/コアごとの CPU 使用率、平均負荷、Linux メモリ、MLA 割り当て、EV74 CMA メモリ、およびプロセス。 |
| ストレージ／ネットワーク | [ストレージとネットワーク パネル](panels/storage-network.md) | eMMC/NVMe の容量と入出力、およびネットワーク全体のトラフィック量。 |

## レポート作成とデータ収集の状況

- [測定モデル](measurement-model.md)は、コレクターの実行頻度とキャッシュについて説明します。
  履歴、チャートのセマンティクス、閾値、古いデータ、利用できない値、およびリセット動作。
- [レポートとJSON形式でのエクスポート機能は、キャッシュスキーマと](reports.md)ドキュメントを記録します。
  `table`、`export`、`sensors`、および`status`コマンド。
- [ローカルエージェントAPI](api.md)は、リアルタイムの読み取りと、その処理の追跡と制御を行います。
  デーモンの Unix ソケット。
- [実行結果の記録と比較](run-comparison.md)は、永続的なデータを記録します。
  チェックポイント、比較実行タブ、データの保持期間、および CSV / JSON 形式でのエクスポート機能。
