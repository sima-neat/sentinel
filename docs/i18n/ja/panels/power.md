# 電源パネル

Sentinelは、専用のスレッドでPMBusの電力レジスタをサンプリングします。Modalix SOMでは、`SoM_Power_Share.py`のリファレンス方式に従います。各レールは50回の読み取りの平均であるため、8つのレールを一巡するのに約1秒かかります。通常のキャッシュ間隔はそれより遅いため、UIはPMBusの生サンプルをすべて表示するのではなく、最新の累積状態を公開します。

## 見出しフィールド

| フィールド | 計算 |
| --- | --- |
| 現在 | 最新のPMBus通信で、少なくとも1つのレールが正常に読み取られた際に、正常に読み取られたすべてのレールの合計値。 |
| セッションの平均値 | デーモン起動以降の、有効なすべてのサンプル数の算術平均値。1つ以上のレールが正常に完了した場合、そのテストは有効とみなされます。 |
| セッションのピーク | デーモン起動開始以降の、有効なサンプルの最大合計数。 |
| 期間 | 電源アキュムレーターが起動してからの経過時間（単調増加時間）。 |
| 有効なサンプル | PMBus：少なくとも1つの設定されたレールが読み取られたパス。 |
| 検査に失敗したサンプル | PMBus：設定されたレールが読み込まれなかったパス。 |

デーモンが再起動されると、すべてのセッション統計がリセットされます。

## 収集家が述べること

- **アクティブ**: 有効なサンプルが少なくとも1つ存在し、最新のパスでデータが取得され、
  現在、レールにエラーはありません。
- **品質低下**: 有効なデータは存在するが、最新のテストで完全に失敗した、または一部で失敗した。
  少なくとも1つのレールでエラーが報告されました。
- **利用できません**: 有効な合計値が収集されていません。

部分的な故障が発生した場合、現在の値、平均値、およびピーク値の合計は、正常な状態のサンプルよりも少ないレール数を含む場合があります。パスが完全に失敗した場合、現在の値とすべてのレールの電力値は、最後に正常に記録された値を保持します。失敗したサンプルとレールのエラーが増加し、状態は劣化（DEGRADED）となります。保持された値を、失敗したパスからの測定値として解釈したり、部分的な合計と完全な合計を、同じ境界を測定したかのように比較したりしないでください。

## レールテーブルのフィールド

- **パワー**は、そのレールに対して最も最近成功した読み取り値です。それ以降に
  読み込みに失敗した場合、この値は最後に成功したときの値を保持し、エラー回数は増加します。
- **サンプル数**は、デーモン起動以降、そのレールで正常に読み取られた回数を表します。
- **エラー**は、ページ選択またはすべてのPMBus読み取りが失敗し、そのレールが値を返さなかった測定回数をカウントします。

部分的に成功したパスの場合、合計値にはそのパスで成功したレールのみが使用され、各レール行は最後に成功した値を保持します。完全に失敗したパスの場合、合計値とレール行の両方が以前の値を保持します。したがって、表示されているレール行を合計すると、部分的な失敗時には現在の値と異なる結果になる可能性があり、完全に失敗した後は、どちらの値も最新の状態ではありません。

## Modalix SOMレール

| 鉄道 | どのようなものを供給しているか |
| --- | --- |
| `SoC and DDR VDD` | 主なSoCおよびDDRドメイン。SoCロジック、メモリコントローラー、およびDDRの動作が影響します。 |
| `HDMI 1.2V` | HDMI 1.2 V PHY および関連回路。 |
| `SoC and DDR VDDQ` | メモリコントローラと DDR デバイス間の DDR I/O 信号伝送領域。 |
| `SoC and DDR VDD2H` | 追加のSoC/DDRメモリ電源ドメイン。 |
| `MLA 0.68V` | 0.68VのMLAコア電源と、MLA演算に最も直接関連するレール。 |
| `PCIe and ETH VP` | PCIeおよびイーサネットのPHY/プラットフォームドメイン。 |
| `SOM Platform 1.8V` | 1.8VのSOM（システム・オン・モジュール）プラットフォームと周辺回路を共有。 |
| `SOM Platform 3.3V` | 3.3VのSOM（システム・オン・モジュール）プラットフォームと周辺回路を共有。 |

`SoC and DDR VDD`と`MLA 0.68V`は、出力電圧と出力電流の積として計算され、電流のステップは0.125Aです。その他の標準的なSOMレールは、PMBusの出力電力の読み取り値を使用し、ステップは0.03125Wです。したがって、サンプル数が増加し、エラーがゼロである`0.00 W`は、レールの分解能における有効なゼロ値のレジスタ読み取り値であり、センサー読み取りの失敗ではありません。

Modalix DVTプロファイルは、`DVT PMIC 0x4d page0`のみを公開し、250ミリ秒ごとに単一の`POUT`値を読み取ります。その合計値は、8つのレールを持つSOMの合計値と直接比較することはできません。

## 測定範囲

現在、監視対象はボード上のレール電源であり、交流コンセント電源やシステム全体の入力電源ではありません。監視対象外のレール、レギュレーターの損失、キャリアボードのコンポーネント、ストレージ、ファン、およびホスト側のデバイスを除外できます。

合計値はすべて推定値です。PMBusデバイスが報告するレギュレータの読み取り値から求めたレールごとの出力電力の合計であり、SOM入力電力の校正済み測定値ではありません。Modalix SOMでは、レジスタ、スケーリング、および平均化はリファレンススクリプト`SoM_Power_Share.py`によって定義されています。Sentinelはそのスクリプトを再現し、そのバージョンを電力ステータスの`method`フィールドで報告します。

同様に、モデルのエネルギーは`MLA 0.68V`だけで表されるわけではありません。推論処理では、DDR、SoC、およびプラットフォームのレールも使用されます。実行結果を比較する際には、プロファイル、レール状態、Sentinelバージョン、ワークロードウィンドウ、および周囲/ボードの条件を記録してください。
