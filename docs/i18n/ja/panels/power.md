# 電源パネル

Sentinelは、専用のスレッドで250ミリ秒ごとに、カーネルのPMBusドライバーから各レールの出力電力（`POUT`）を読み取ります。通常、キャッシュ間隔はそれより遅いため、UIはすべての電力読み取り値を表示するのではなく、最新の累積状態を公開します。

## ソース

各レールは、PMBusレギュレーターのhwmonデバイスにある1つの`pout`チャネルです：`/sys/bus/i2c/devices/<bus>-<address>/hwmon/hwmon*/power<N>_input`（単位はマイクロワット）。`power<N>_label`がチャネル名を示します（たとえば、PMBusページ0の場合は`pout1`）。Sentinelは、デバイスをI2Cアドレスで、チャネルをラベルで特定し、`hwmonN`やチャネル番号では特定しません。カーネルドライバーが独自のロックの下でPMBusページを選択してレジスタを読み取るため、レギュレーターを読み取る他のプログラムがSentinelの読み取り値を破損させることはありません。

Modalixでは、レギュレーターはIRPS5401デバイスです。デバイスツリーで宣言されていますが、`irps5401`モジュールは自動的には読み込まれないため、Sentinelサービスは起動前に`modprobe irps5401`を実行します。ドライバーがバインドされていない場合、電力は取得できず、コレクターのエラーに読み込むべきモジュール名が示されます。

## 見出しフィールド

| フィールド | 計算 |
| --- | --- |
| 現在 | 最新のパスにおける、設定されたすべてのレールの合計値。いずれかのレールを読み取れなかった場合は空になります。 |
| セッションの平均値 | デーモン起動以降の、すべての完全なパスの合計値の算術平均値。すべてのレールが読み取られた場合、そのパスは完全とみなされます。 |
| セッションのピーク | デーモン起動以降の、完全なパスの合計値の最大値。 |
| 期間 | 電源アキュムレーターが起動してからの経過時間（単調増加時間）。 |
| 有効なサンプル | 設定されたすべてのレールが読み取られたパス。 |
| 検査に失敗したサンプル | 設定されたレールのうち少なくとも1つを読み取れなかったパス。 |

デーモンが再起動されると、すべてのセッション統計がリセットされます。

## 収集家が述べること

- **アクティブ**: 完全なパスが少なくとも1つ存在し、最新のパスで
  すべてのレールが読み取られました。
- **品質低下**: 完全なパスは存在するが、最新のパスで少なくとも1つの
  レールを読み取れませんでした。
- **利用できません**: 完全なパスがまだ収集されていません。

Sentinelは、以前の読み取り値を現在の値として表示することはありません。レールを読み取れない場合、そのレールの電力値と現在の値は次に成功するパスまで空になり、失敗したサンプルとそのレールのエラーが増加し、状態は劣化（DEGRADED）となります。平均値とピーク値には完全なパスのみが含まれるため、すべての合計値は同じレールを対象とします。

## レールテーブルのフィールド

- **パワー**は、最新のパスにおけるそのレールの読み取り値です。その読み取りに
  失敗した場合は空になります。
- **サンプル数**は、デーモン起動以降、そのレールで正常に読み取られた回数を表します。
- **エラー**は、そのレールのカーネル`power<N>_input`ファイルの読み取りに失敗した回数をカウントします（たとえば、ドライバーがバインドされていない間）。

## Modalix SOMレール

| 鉄道 | どのようなものを供給しているか |
| --- | --- |
| `SoC and DDR VDD` | 主なSoCおよびDDRドメイン。SoCロジック、メモリコントローラー、およびDDRの動作が影響します。 |
| `HDMI 1.2V` | HDMI 1.2 V PHY および関連回路。 |
| `SoC and DDR VDDQ` | メモリコントローラと DDR デバイス間の DDR I/O 信号伝送領域。 |
| `SoC and DDR VDD2H` | 追加のSoC/DDRメモリ電源ドメイン。 |
| `MLA 0.68V` | 0.68VのMLAコア電源と、MLA演算に最も直接関連するレール。 |
| `PCIe and ETH VP` | PCIeおよびイーサネットのPHY/プラットフォームドメイン。 |
| `SOM Platform 1.8V` | 1.8VのSOM（システム・オン・モジュール）プラットフォームと周辺回路を共有。 |
| `SOM Platform 3.3V` | 3.3VのSOM（システム・オン・モジュール）プラットフォームと周辺回路を共有。 |

`SoC and DDR VDD`と`MLA 0.68V`は、0.25Wのレポートステップを持ちます。その他の標準的なSOMレールは、0.03125Wのステップを持ちます。したがって、サンプル数が増加し、エラーがゼロである`0.00 W`は、レールの分解能における有効なゼロ値のレジスタ読み取り値であり、センサー読み取りの失敗ではありません。

Modalix DVTプロファイルは、`DVT PMIC 0x4d page0`のみを公開します。その合計値は、8つのレールを持つSOMの合計値と直接比較することはできません。

## 測定範囲

現在、監視対象はボード上のレール電源であり、交流コンセント電源やシステム全体の入力電源ではありません。監視対象外のレール、レギュレーターの損失、キャリアボードのコンポーネント、ストレージ、ファン、およびホスト側のデバイスを除外できます。

同様に、モデルのエネルギーは`MLA 0.68V`だけで表されるわけではありません。推論処理では、DDR、SoC、およびプラットフォームのレールも使用されます。実行結果を比較する際には、プロファイル、レール状態、Sentinelバージョン、ワークロードウィンドウ、および周囲/ボードの条件を記録してください。
